# メールテンプレート更新ガイド

## 概要
Supabase のメールテンプレートを日本語化し、ユーザーフレンドリーな内容に更新します。

## 更新手順

### 1. Supabase Dashboard にアクセス

1. [Supabase Dashboard](https://supabase.com/dashboard) にログイン
2. プロジェクト `sfscmpjplvxtikmifqhe` を選択
3. 左メニューから **Authentication** → **Email Templates** を選択

### 2. パスワードリセットメールを更新

**テンプレート名**: `Reset Password`

#### Subject（件名）
```
パスワードのリセット - Casto
```

#### Body（本文）
```html
<h2>パスワードのリセット</h2>

<p>パスワードリセットのリクエストを受け付けました。</p>

<p>以下のリンクをクリックして、新しいパスワードを設定してください：</p>

<p><a href="{{ .ConfirmationURL }}">パスワードをリセットする</a></p>

<p><strong>※ このリンクは1時間有効です。</strong></p>

<p>このメールに心当たりがない場合は、削除してください。パスワードは変更されません。</p>

<hr>

<p style="font-size: 12px; color: #666;">
このメールは Casto からお送りしています。
</p>
```

### 3. アカウント確認メールを更新（オプション）

**テンプレート名**: `Confirm signup`

#### Subject（件名）
```
メールアドレスの確認 - Casto
```

#### Body（本文）
```html
<h2>メールアドレスの確認</h2>

<p>アカウント登録ありがとうございます。</p>

<p>以下のリンクをクリックして、メールアドレスを確認してください：</p>

<p><a href="{{ .ConfirmationURL }}">メールアドレスを確認する</a></p>

<p>このメールに心当たりがない場合は、削除してください。</p>

<p>※ このメールは自動送信されています。返信はできません。</p>

<hr>

<p style="font-size: 12px; color: #666;">
このメールは Casto からお送りしています。
</p>
```

### 4. 保存と確認

1. 各テンプレートの **Save** ボタンをクリック
2. テスト送信で内容を確認

## テスト手順

### パスワードリセットメールのテスト

1. `/admin/forgot-password` にアクセス
2. 登録済みのメールアドレスを入力
3. メールを確認
   - ✅ 件名が日本語になっている
   - ✅ 本文が日本語になっている
   - ✅ 「1時間有効」の記載がある
   - ✅ リンクが正しく動作する

## 注意事項

- **{{ .ConfirmationURL }}** は Supabase が自動的に置き換える変数です。削除しないでください。
- テンプレートの変更は即座に反映されます。
- 本番環境で変更する場合は、必ず事前にテストしてください。

## トラブルシューティング

### メールが届かない
- Supabase の無料プランでは1時間に4通までの制限があります
- 迷惑メールフォルダを確認してください
- Supabase Dashboard → Authentication → Logs でエラーを確認してください

### リンクが動作しない
- `supabase/config.toml` の `additional_redirect_urls` を確認してください
- Workers の `WEB_URL` 環境変数を確認してください
